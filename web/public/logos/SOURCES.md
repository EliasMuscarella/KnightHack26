# Logo sources

Downloaded at development time from Wikimedia Commons (the web app makes no logo requests at runtime).
New logos are found by `scripts/fetch_logos.py`: it looks up the Wikidata item whose "Central Index
Key" (P5531) equals the company's SEC CIK, takes "small logo or icon" (P8972) when present, else "logo
image" (P154), keeps only SVG files of at most 400 KB, and rebuilds each file from an element and
attribute allowlist (DECISIONS.md D-034): no `<script>`, `<image>`, `<foreignObject>`, `<a>`,
animation, `on*` attributes, external `href`/`url()`, DOCTYPE/entities, comments, metadata or editor
namespaces remain. The artwork itself is unchanged. The logos are trademarks of their owners and
identify the company whose filings are shown.

The five rows for AAPL, AMZN, CRWD, NVDA and SF predate the script (D-031, sanitized by hand); their
Wikidata column is the CIK-matched item, and Stifel has no CIK on Wikidata.

Add a logo: run `uv run python scripts/fetch_logos.py --dry-run`, then without `--dry-run`. For a
company the script cannot find, put a genuine SVG here as `{TICKER}.svg`, add a row above by hand and add
the ticker to the generated block in `web/src/lib/logos.ts` (tickers not listed there render a monogram and
never request an image).
When only a raster image exists (Byline Bancorp), or the team supplies one (Adobe, Lockheed Martin), save a
tight PNG crop on a white background as `{TICKER}.png` and also add the ticker to `RASTER_LOGOS` in `logos.ts`;
the script never replaces a hand-added PNG.
